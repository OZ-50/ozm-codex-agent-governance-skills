Instructions for coding agents working in this repository.

## Scope

This repository publishes the OZM Skills package: a Codex-native governance skill pack for AI coding agent governance, agentic coding loops, claim ceilings, evidence gates, and AGENTS.md-aware workflows.

This repository is not a production agent OS, hosted runtime, scheduler, background worker, MCP marketplace, or commercial support surface.

## Required Boot Order

For OZM-governed work:

1. Read this `AGENTS.md`.
2. Load `ozone-manager/SKILL.md`.
3. Classify the latest user request before acting.
4. Load only the current-phase OZM child skill plus mandatory companions.
5. State the current claim ceiling before using completion, verification, readiness, or acceptance wording.

## Agentic Coding Loop And Goal Boundary

Generic continuous-progress wording such as "continue until done", "run until done", "持续推进", "自动推进", or "直至完成" activates OZM standing autonomy as current-thread text control only.

Native Codex `/goal`, explicit `create_goal`, or an already-active native Goal is a separate runtime carrier. It applies only when explicitly requested or already active.

When native Goal is active, OZM still owns requirement load, dispatch freeze, evidence floor, claim ceiling, reentry, and closeout.

After resume, compaction, handoff, long wait, replay, replacement, or role switch, reload `ozone-manager`, the current-phase child skill, mandatory companions, repository instructions, and owner surfaces before tool calls or file mutation.
