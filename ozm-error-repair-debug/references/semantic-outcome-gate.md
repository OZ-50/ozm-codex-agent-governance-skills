# Semantic Outcome Gate

- Repair packet schema requires repro_steps, failure_signature, root_cause_hypothesis, minimal_change_set, regression_guard, non_claims.
- Closeout must explain why not broader scope and what remains unproven.
- No-op repair and harness-noise misclassification belong in heldout eval.
