# Support

Use the lowest-risk channel that matches the request:

- GitHub Discussions: questions, design notes, adoption discussion, and examples.
- Discord OZ-Sir: lightweight community coordination at https://discord.gg/UxF32zjqR.
- GitHub Issues: reproducible bugs, documentation gaps, governance conflicts, and deterministic-check failures.
- Security: follow `SECURITY.md` and avoid public payloads or sensitive details.

This repository is a public pre-1.0 reference package. Community support does not imply a commercial SLA, hosted runtime, production readiness, or accepted governance behavior.
