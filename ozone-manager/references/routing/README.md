# OZM Routing Data

`route-rules.json` is the machine-owned route-rule and absorbed-donor mapping data source for `ozm_skill_graph.py`.

Edit keyword, target, role-flag, generic-token, or absorbed-donor owner changes in `route-rules.json`, rebuild `../skill-graph.json`, then run `ozm_eval_suite.py`. Keep large historical rationale in `../archive/` or `../hardening-log.md`; this folder should stay focused on active routing data and routing references.
