# Semantic Outcome Gate

- Bootstrap receipt is schema-governed by `references/schemas/bootstrap-minimal.schema.json`.
- Eval reproducibility is bound by `references/schemas/eval-run-manifest.schema.json` and the generated `references/eval-run-manifest.json`.
- Route results must expose strong rules, weak rules, seed fill, suppressed rules, route decision trace, and final owner rationale.
- Candidate route, prompt inventory, or metadata mention is never activation. Actual child hydration and activation-effect posture must be visible before governed execution, audit consumption, closeout, or positive claims.

## Schema Anchors

- `references/schemas/bootstrap-minimal.schema.json`
- `references/schemas/eval-run-manifest.schema.json`
- `references/schemas/activation-effect-contract.schema.json`
- `references/schemas/script-permission.schema.json`
