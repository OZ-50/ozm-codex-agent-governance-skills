## External Research Summary

- OpenAI skill guidance favors small building-block skills with progressive disclosure rather than one massive workflow.
- Long-horizon agent papers on ACON, Context-Folding, Memory-as-Action, MemexRL, and related memory systems support adaptive context curation, indexed memory, and active working-context control.
- OZM adopts the compact governance delta: preserve critical identifiers, make summaries navigation-only, require owner reread after compression, and maintain retrieval/cleanup rules for file-backed context.

## Non-Claims

- The absorbed scripts are helper tools, not proof gates.
- Context optimization does not raise acceptance claims.
- A compressed summary is never controller truth unless the controller explicitly accepts it as such.
