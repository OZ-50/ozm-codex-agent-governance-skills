# Reference Method Grounding Scripts

These scripts are deterministic companion gates for `ozm-reference-method-grounding`.

- `method_anchor_check.py` validates paper/reference method atoms, adoption posture, proof targets, non-portable boundaries, and claim ceiling.
- `reference_gap_check.py` validates source-backed gap ledgers, reduced/closed gap evidence, method atom linkage, and parity/negative proof requirements.

Use these scripts after a reference method map or paper method card is drafted, before dispatching reference-guided implementation packets, and before positive reference-progress closeout.
