# Semantic Outcome Gate

- Paper Method Card, Method Atom, Adoption Contract, Source-backed Gap Ledger, and Execution Anchor Contract are schema-governed.
- Reference-guided packet without anchor id, gap id, or proof_surface is blocked.
- Closeout must report gap status open->reduced/closed evidence, not generic reference wording.

## Schema Anchors

- `references/paper-method-card.schema.json`
- `references/method-adoption-contract.schema.json`
- `references/source-backed-gap-ledger.schema.json`
- `references/execution-anchor-contract.schema.json`
